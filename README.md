# OTT Renew Prototype

This folder contains a simple browser-based prototype for feedback sharing without TestFlight.

## How to use

1. Open `index.html` in a browser.
2. Click through the screens like a product walkthrough.
3. Use the feedback section to copy notes or open email.

## How to share

Free options:

1. Send the `prototype` folder as a zip.
2. Upload this folder to a free static host like GitHub Pages, Netlify, or Vercel.
3. Share screenshots or screen recordings based on the prototype.

## Notes

- This prototype is intentionally backend-free.
- It is designed for feedback on layout, copy, hierarchy, and general product feel.
